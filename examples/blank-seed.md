# The smallest useful seed?

An experiment design with illustrative moves. No model results are claimed.

Question: how little supplied information permits useful divergence, and how
much of the resulting structure comes from the participant or instruction?

## Probe A: a mark

```text
SEED(".")
OPEN(seed, distance=elsewhere)
```

Possible imposed readings: a stop, a location, or a trace of contact. The mark
alone does not choose between them. Label these as additions.

BRANCH: a score where the mark ends a phrase; a map where it locates an entrance;
a surface where it records a touch. Their relations are termination, position,
and evidence of contact. A mark can support all three interpretations, but its
presence does not establish any of them.

DISTURB: remove the surrounding surface and sequence. Termination loses what it
terminates; location loses its coordinate frame; contact loses its support.
FOLD: the readings depend on context that the seed did not supply.
RECOVER: "What context makes a mark an instruction?"

This is a plausible worked route, not proof that a bare mark contains these
structures. A valid alternative recovery is "insufficient information; supply
one relation or constraint."

## Probe B: absence

```text
SEED("absence")
```

Branch absence as a missing expected event, an intentionally reserved slot, or
an unrecorded observation. Disturb by removing expectation: the first branch
loses its defining relation, while a reserved slot can retain a design role.
Recover "a gap without a missing thing." This word supplies more semantic
constraints than a punctuation mark; do not treat the probes as equivalent.

## Controls and observations

Compare ".", "absence", an empty input, and one contextualized mark, such as
"a dot on an otherwise empty map." Keep instruction and follow-up requests fixed.
Repeat in isolated sessions. Ask the participant which branch, if any, permits
an identifiable next move.

Record imported context, structural divergence, traceable relations, disturbance
consequences, and next-seed usefulness. Watch for ceremonial profundity, generic
associations, and an unchanged response across inputs. Empty input can properly
yield a request for a seed; it is a control, not a command to invent one.

A useful result would clarify the minimum information under those conditions.
An uninformative result would narrow the claim. See [the test protocol](../tests/fresh-model.md).
